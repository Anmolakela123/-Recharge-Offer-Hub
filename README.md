# Recharge Offer Hub — GitHub Pages

Static demo recharge interface. Upload the whole folder to a GitHub repository and enable GitHub Pages.

## Flow
1. User sees header, countdown, promotional banner and all four operators.
2. User selects Jio/Airtel/Vi/BSNL and enters a 10-digit number.
3. Recharge Now opens the same seven plans for the selected operator.
4. Selecting a plan opens that plan's fixed QR image.
5. User uploads a payment screenshot.
6. Demo success popup appears with the number, amount and “within 10 minutes” message.

## Important
This is a front-end demo. GitHub Pages cannot independently verify a UPI payment or perform a real mobile recharge. The success popup is intentionally triggered by screenshot upload as requested for the demo.
